# 🍰 Mata Cake - Artisan Bakery & Cake Studio

A complete full-stack web application for an artisan bakery and cake shop. This project includes a customer-facing website and an admin panel for managing products, categories, orders, and more.

## ✨ Features

### 👥 User Side (Customer Website)
- 🏠 **Home Page** - Hero section with featured products
- 🍰 **Cakes Page** - Browse all available cakes with prices
- 🛒 **Shopping Cart** - Add/remove items, update quantities
- 📝 **Custom Order** - Request personalized cake designs
- 📞 **Contact Page** - Send messages to the bakery
- ✅ **Checkout** - Place orders with delivery details

### 👨‍💼 Admin Panel
- 🔐 **Secure Login** - Admin authentication system
- 📊 **Dashboard** - View statistics (products, orders, messages)
- 🏷️ **Category Management** - Add/delete cake categories
- 🎂 **Product Management** - Add/delete cakes with prices
- 📦 **Order Management** - View orders and update status
- ✏️ **Custom Requests** - View customer cake design requests
- 💬 **Messages** - Read contact form submissions

### 🛠️ Technical Features
- 📱 **Responsive Design** - Works on desktop, tablet, and mobile
- 🛒 **Session-based Cart** - Persistent cart using PHP sessions
- 🗄️ **Database Integration** - MySQL database for data storage
- 🎨 **Modern UI** - Clean design with smooth animations
- 🔄 **AJAX-ready** - Form submissions without page reload
